📈 Numerical Prediction

Grade 11 · Computational Science ⏱ 4 hours 🧑‍🏫 Activity 7 — predict the future with data
🎯 What you'll learn

📊 Build models

Use scatter plots & trend lines to find patterns in real data.

🧮 Linear equations

Create y = mx + c from data and make numeric predictions.

📉 Measure error

Calculate prediction errors to know how accurate your model is.

💻 Software tools

Use spreadsheets to automate trend lines & equations.

🔑 Core ideas
Numerical prediction uses historical data to forecast a number: sales, price, views, etc.
Scatter plot → trend line → linear equation → prediction
Error = actual – predicted. We use squared error so that big mistakes stand out.
Sum of squared errors (SSE) measures overall model accuracy.
y = m·x + c  |  m = (y₂ – y₁) / (x₂ – x₁)  |  Error² = (y – ŷ)²

🧮 Prediction error & tools

📉 Sum of squared errors (SSE)
SSE = Σ (y – ŷ)²
Lower SSE = better fit. Use it to compare manual vs. software models.

💻 Software (spreadsheet)
• Insert scatter plot
• Add trendline → linear
• Check “Display equation” & “Display R²”
• Instant predictions!

💬 discuss with your class
  • When would you prefer a manual calculation over software? When would software be essential?
  • What does a high error tell you about your model? Should you always trust the trend line?
  • If your prediction error is large, what could you do to improve it? (Hint: more data, different type of trend line, etc.)
